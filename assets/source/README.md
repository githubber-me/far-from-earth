# SI-generated artwork sources

These PNG/WebP images were generated with OpenAI image generation. Created by Anthahkarana.

They are preserved, unmodified source masters, not labeled submission exports. This folder is outside the website's public directory. Use the labeled SVG versions in `public/assets/` for sharing or submission. Run `node scripts/disclose-artwork.mjs` to regenerate those versions. See `SI_DISCLOSURE.md` and `docs/demo/asset-prompts.md` for provenance.
